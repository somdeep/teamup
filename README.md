# TeamUp

TeamUp helps Art of Living coordinators find and invite volunteers for seva. The public landing page is ready to preview. The sign-in and onboarding buttons display a launch notice until those flows are available.

## Run locally

With Node.js 22.14 or newer, run `npm ci` and `npm run dev`, then open [localhost:3000](http://localhost:3000).

Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build` before deploying. The landing page builds without any Supabase environment variables.
